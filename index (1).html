El debugging (o depuración) es el proceso de buscar, encontrar y solucionar errores 
(llamados "bugs") en el código de un programa informático. 
 
Cuando un programa no funciona como debería, no realiza los cálculos correctos o se 
cierra inesperadamente, significa que hay un error en la lógica o en la sintaxis. El 
debugging sirve para corregir esos problemas. 
 
Pasos principales del debugging 
• Reproducir el error: Identificar exactamente qué acciones del usuario o qué 
datos provocan que el programa falle. 
 
• Localizar el fallo: Examinar el código para encontrar la línea o la sección exacta 
donde ocurre la falla. 
 
• Analizar la causa: Entender por qué el código no se comporta de la manera 
esperada. 
 
• Corregir el código: Hacer las modificaciones necesarias para solucionar el 
problema. 
 
• Probar la solución: Verificar que el error se haya resuelto sin introducir nuevos 
fallos en otras partes del programa. 
 
Herramientas y técnicas comunes 
• Puntos de interrupción (Breakpoints): Marcas que se colocan en el código 
para pausar la ejecución del programa en una línea específica y revisar el estado 
de las variables en ese momento. 
 
• Ejecución paso a paso: Avanzar por el programa línea por línea para observar el 
flujo de ejecución. 
 
• Impresión de mensajes (Print debugging): Insertar instrucciones para mostrar 
el valor de variables o mensajes en la consola a medida que se ejecuta el 
código.

1. Lenguaje Ensamblador (AVR para ATmega328P - Arduino Uno) 
A nivel de hardware, el chip ATmega328P utiliza sus contadores/temporizadores 
hardware (Timers) para generar las señales de modulación por ancho de pulsos (PWM). 
En el pin 9 (asociado al registro OCR1A), la instrucción equivale a escribir los valores del 
ciclo de trabajo directamente en ese registro: 
 
Fragmento de código 
.def brightness = r16 
.def step = r17 
 
setup: 
    ; Configura el Pin 9 (PB1) como salida 
    sbi   0x04, 1            ; DDRB |= (1 << PB1) 
 
    ; Configura Timer1 para PWM rápido de 8 bits 
    ldi   r18, 0x81 
    sts   0x80, r18          ; TCCR1A = Fast PWM 8-bit 
    ldi   r18, 0x0B 
    sts   0x81, r18          ; TCCR1B = Prescaler 64 
 
loop: 
    ; --- Bucle 1: Incrementar brillo --- 
    clr   brightness         ; brightness = 0 
    ldi   step, 5 
 
fade_up: 
    sts   0x88, brightness   ; Escribe en OCR1AL (analogWrite en pin 9) 
    rcall delay_30ms         ; Espera 30 ms 
    add   brightness, step   ; brightness += 5 
    brcc  fade_up            ; Repite hasta sobrepasar 255 
 
    ; --- Bucle 2: Decrementar brillo --- 
    ldi   brightness, 255    ; brightness = 255 
 
fade_down: 
    sts   0x88, brightness   ; Escribe en OCR1AL 
    rcall delay_30ms         ; Espera 30 ms 
    sub   brightness, step   ; brightness -= 5

Concepto clave: ¿Cómo logra Arduino el brillo analógico? 
Los pines con el símbolo ~ no entregan un voltaje variable real (como 2.5V), sino que 
conmuta el pin entre 0V y 5V miles de veces por segundo. Modificando el registro OCR1A 
(el parámetro brightness), cambias la proporción de tiempo que permanece 
encendido frente a apagado (Pulse-Width Modulation).

El lenguaje ensamblador es un lenguaje de programación de bajo nivel que sirve como 
puente directo entre el código fuente y las instrucciones de máquina que ejecuta el 
procesador. 
A diferencia de los lenguajes de alto nivel (como Python, C# o Java), ensamblador se 
corresponde casi de forma directa con la arquitectura física de la CPU.

P15 
 George Boole (1815–1864) fue un brillante matemático y filósofo británico inventó 
el sistema de lógica matemática que hoy conocemos como álgebra de Boole. Su 
trabajo es la base fundamental de toda la programación y la tecnología digital actual. 
¿Por qué es tan importante? 
• Unió la lógica y las matemáticas: Antes de Boole, la lógica era una rama de la 
filosofía. Él demostró que el pensamiento lógico se podía expresar mediante 
ecuaciones algebraicas. 
• El lenguaje de las computadoras: Redujo toda la lógica a solo dos opciones: 1 
(verdadero) y 0 (falso). Un siglo después, este sistema binario se convirtió en el 
código que utilizan los microchips y las computadoras para procesar 
información. 
El tipo long de Python permite almacenar números de cualquier precisión, estando 
limitados solo por la memoria disponible en la máquina. Al asignar un número a una 
variable esta pasará a tener tipo int, a menos que el número sea tan grande como para 
requerir el uso del tipo long.

Capítulo 2: Variables, Expresiones y Sentencias 
• Tipos de datos básicos: Python maneja enteros (int, como 17), números de 
punto flotante (float, con decimales como 3.2), y cadenas de texto (str, 
encerradas entre comillas como 'Hola'). 
• Variables y asignación: Una variable es un nombre que se refiere a un valor (ej. 
n = 17). Los nombres de las variables deben ser mnemónicos (descriptivos), 
comenzar con letra o guion bajo, y nunca usar palabras reservadas de Python 
(como class, if, etc.). 
• Operadores: Símbolos para realizar cálculos (+, -, *, /, división entera //, 
exponenciación ** y módulo %). El operador + también sirve para concatenar 
(unir) cadenas de texto. 
• Orden de operaciones: Se sigue la jerarquía matemática (PEMDAS): Paréntesis, 
Exponentes, Multiplicación/División y Suma/Resta de izquierda a derecha. 
• Entrada de datos: La función input() permite recibir datos del usuario en 
forma de cadena. Para operar matemáticamente con ellos, se deben convertir 
usando funciones como int() o float(). 
• Comentarios: Se indican con # y son ignorados por Python; sirven para 
documentar el código. 
• # Programa de cálculo de salario...: Es un comentario. Python lo 
ignora, pero ayuda a los humanos a entender el propósito del código. 
• nombre = input('¿Cómo te llamas?\n'): Utiliza la función input() para 
pedir un valor por teclado. Lo que escribe el usuario se guarda en la variable 
nombre como una cadena (str). El \n añade un salto de línea. 
• horas_str = input(...): Solicita otro dato de texto al usuario y lo almacena 
temporalmente en una variable de tipo str. 
• horas = int(horas_str): Utiliza la función de conversión int() para 
transformar la cadena de texto anterior en un número entero (int), permitiendo 
realizar operaciones matemáticas con él. 
• tarifa = float(tarifa_str): Convierte la entrada del usuario en un 
número con decimales de tipo punto flotante (float). 
• salario_bruto = horas * tarifa: Es una expresión que utiliza el operador 
de multiplicación (*) entre dos variables numéricas, asignando el resultado a 
salario_bruto. 
• horas_pares = (horas % 2 == 0): Utiliza el operador módulo (%) para 
obtener el resto de dividir las horas entre 2. Si el resto es 0, el resultado lógico 
guardado será True (verdadero).
